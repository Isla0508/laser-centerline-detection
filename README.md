# 让一束激光变成一条可以被计算的线

这是我做的一个小型计算机视觉项目。

一开始我只是想解决一个很具体的问题：**图片里的红色激光，到底能不能被程序“找出来”？**

最后我把它做成了一个简单的激光条纹提取工具：输入一张激光照射物体的照片，程序自动找到主要激光区域，再提取它的中心线，并把中心线坐标保存下来。

## 它实际上在做什么？

大致可以理解成：

**图片 → 找到红色激光 → 去掉小噪声 → 找到主要区域 → 提取中心线 → 得到坐标**

程序会先用 OpenCV 把红色激光从背景里分离出来，再通过连通区域分析保留主要激光区域，最后利用骨架化得到一条较细的中心线。

为了方便观察，程序还会把检测到的中心线用绿色画在原图上。

## 为什么和光电专业有关

这件事本质上就是把**光学信息转换成可以计算的数字信息**。

激光负责提供明显的光学特征，相机负责采集图像，计算机视觉负责从图像中把这条“光”提取出来。继续往下做，就可以和**机器视觉、激光三角测量、结构光测量、非接触式检测**联系起来。

所以这个项目虽然不大，但它让我第一次真正把“光”从一张照片里提取成了数据。

## 目前已经做到

- 可以提取红色激光区域
- 可以处理测试图片和真实激光图片
- 可以提取激光中心线
- 可以将中心线坐标保存为 CSV
- 测试图和真实图使用同一套算法处理

## 怎么运行

安装依赖：

```bash
pip install opencv-python numpy scikit-image
```

项目结构：

```text
project/
├── main.py
└── images/
    ├── test.jpg
    └── real.jpg
```

运行：

```bash
python main.py
```

## 现在还不完美

目前主要还是基于**颜色和亮度**来找激光，所以遇到很强的红色反光、复杂背景时，仍然可能出现误检。

我现在做的是“把激光线找出来”，还没有做到完整的三维重建和高精度测量。

## 后面可以怎么继续

下一步可以在现有中心线的基础上加入**标定和激光三角测量**，进一步把“图像中的一条线”变成“物体真实的轮廓数据”，最终往结构光三维测量方向扩展。
